# Posłowie
Strona księgarni oparta o technologię React z TypeScriptem.

## Funkcje
* **Katalog książek**: Przeglądanie dostępnych pozycji z filtrowaniem.
* **System zamówień**: Historia zamówień z linkami do szczegółów produktów.
* **Koszyk**: Zarządzanie produktami przed zakupem.
* **Profil użytkownika**: Logowanie (JWT) i podgląd historii zakupów.
* **Ulubione**: Dodawanie pozycji do ulubionych i zapisywanie ich dla uzytkownika.
* **Oceny**: Mozliwość dodawania i usuwania opinii wraz z oceną.

## Technologie
### Frontend:
* **React** 
* **React Router**
* **CSS Modules** 

### Backend:
* **Node.js / Express**
* **Database**: Sequelize
* **Autentykacja**: JWT (JSON Web Tokens)

## API Endpoints (Przykłady)
| `GET` | `/api/books` | Pobiera listę wszystkich książek |
| `GET` | `/api/orders` | Pobiera zamówienia zalogowanego użytkownika |
| `POST` | `/api/orders` | Tworzy nowe zamówienie |
